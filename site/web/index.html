Biology translated, not disguised.

A worm cannot see a webpage or click a mouse. The interface converts the browser into a virtual environment, advances a connectome-based model, and converts locomotion-related activity back into motion. Each artificial boundary is documented.

01 / ENVIRONMENT

Browser surface

A page is treated as a virtual plate with gradients, targets, and boundaries.

02 / SENSORY

ASEL / ASER

Local changes become controlled input to named chemosensory neurons.

03 / GRAPH

302 neurons

Activity propagates across Cook 2019 chemical and electrical connectivity.

04 / MOTOR

AVA / AVB / PVC

Command-interneuron activity is decoded into forward, reverse, and steering.

05 / INTERFACE

Worm cursor

The virtual body moves; a separately disclosed signal maps to interaction.

Research thread · Alzheimer’s / PFE

Why pair the story with Pfizer?

A 2004 Pfizer-affiliated study used C. elegans presenilin biology in a screening assay relevant to Alzheimer’s drug discovery. That historical connection motivates the planned PFE pairing; it does not imply sponsorship, endorsement, or a worm-derived treatment.

Read the paper

The boundary of the claim.

  • Real: neuron identities, anatomical partners, Cook 2019 connection records, and named circuitry.
  • Modeled: dynamics, chemical signs in the fast controller, scale factors, thresholds, and temporal behavior.
  • Designed: webpage-to-sensory encoding, motor-to-cursor decoding, and the interaction mapping.
  • Rig-controlled: wallet handling, predetermined token metadata, missing form fields, signing, and confirmation.
  • Not claimed: sight, language understanding, intention, consciousness, medical discovery, or financial judgment.
  • Safety: live broadcasting is disabled by default and any funded action requires a separate human decision.
