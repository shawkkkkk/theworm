The honest architecture

The worm changes language.
It does not create language alone.

This follows the experimental pattern of the Fly Language Model: a pretrained model supplies language ability, the connectome supplies a fixed stateful pathway, and only a small readout is trained.

01 / LANGUAGE

Frozen backbone

Provides tokenization, vocabulary, grammar, knowledge, and the baseline next-token scores.

02 / CONNECTOME

302-node reservoir

Each token embedding produces one causal update through fixed Cook 2019 worm connectivity.

03 / READOUT

Trained adapter

A small bounded readout adjusts the backbone’s scores without changing the worm graph.

The biological claim stops at the wiring. The input projection, recurrence equation, output pooling, token interface, and training objective are designed in software. The states are not measured thoughts, spikes, or understanding.
